# React Weather App

A responsive weather application built using React.js that allows users to search for a city and view its current weather information.

## Features

* Search weather by city
* Displays current temperature
* Shows weather conditions
* Displays humidity and wind speed
* Responsive user interface
* Fetches real-time weather data using a weather API

## Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Vite
* Weather API

## How to Run

1. Clone the repository
2. Open the project folder
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.
